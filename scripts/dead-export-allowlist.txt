# Dead-export allowlist for `bun run check:dead-exports`.
#
# An entry is `path/to/file.ts: ExportName`. `#` lines are the reason and
# attach to the entries below them until a blank line. A directory prefix or a
# bare file path still parses, but it blankets a surface, so this list does
# not use one. Anything else fails the gate.
#
# The guard's finding set is the union of knip's default scan and its
# `--production` agent-workspace scan. Stale entries fail the gate. An export
# with no production importer is deleted, not added here. The upstream
# `vendor/` mirror and completion-eval fixtures (loaded by path from
# evals/completion/tasks.json, not imported) are knip `ignore` entries.
#

# those names are not listed. `agent` in `agent.ts` is the definition the
