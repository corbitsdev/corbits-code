# Word List

Standardized spellings, terms we use, terms we avoid, and special cases.
When a word isn't on this list, defer to the AP Style Guide.

---

## Corbits-Specific Terms

- **Corbits** — always capitalize the C
- **neoteam** — lowercase when generic; **Neoteams** capitalize when
  referring to the category
- **Interchange** — always capitalize
- **Faremeter** — always capitalize
- **Agent Ops** — capitalize when referring to the role/function;
  **Agent Operations** — capitalize when referring to the business unit
- **provenance** — lowercase, it's a concept not a brand
- **federation** — lowercase
- **orchestration** — lowercase

## Capitalization Rules

### Always lowercase

- agent (unless starting a sentence or part of a proper noun)
- blockchain (unless starting a sentence)
- internet (never capitalize)
- online (never capitalize)
- website (never capitalize)

### Always uppercase

- AI (not "Ai" or "ai" unless referring to the name Ai)
- API
- SDK
- UI
- UTC (for time zones)
- US, UK, EU (when abbreviating countries)

## Terms We Use

### Agent industry terms

- **agent** — our standard term, not "AI agent" or "bot" once context is
  established
- **Agent Operator** — the human managing agents
- **agent team** — two words when generic and not referring to teams we
  manage; use neoteam; **Neoteam** when referring to the category
- **coordination** — what Interchange does
- **deployment** — getting agents running
- **handoff** — when one agent passes work to another
- **provenance** — verifiable history of agent actions
- **settlement** — when agents pay each other via Faremeter

### Words that describe agent capabilities

analyzes, coordinates, decides (only in specific contexts, not implying
human-like agency), executes, negotiates, processes, recommends, routes,
synthesizes

## Terms to Avoid

### Hype and fluff

- autonomous (implies more independence than agents actually have)
- brilliant, intelligent, smart, wise (attributing human cognition to agents)
- cognitive (implies thinking; agents process, they don't cognize)
- cutting-edge, groundbreaking, revolutionary, world-changing (let the
  product speak)
- disruptive (unless specifically discussing Clayton Christensen's theory)
- magical, automagical (we're infrastructure, not magic)
- next-generation, future-proof, scalable (meaningless modifiers)
- thought leader (just don't)
- learnings (use "insights" or "findings")
- synergy, paradigm shift, leverage (as verbs), incentivize

### Anthropomorphizing agents

- AI colleague, AI employee, AI worker (agents are teammates, not employees)
- feels, knows, learns, understands, perceives, senses (use "processes,"
  "detects," "updates weights")
- brain, memory, nerves, eyes, hands (use "storage," "context," "API,"
  "interface")
- wants, prefers, intends, chooses (agents execute logic, they don't have
  preferences)
- trusts, believes, hopes (agents verify signatures, they don't have
  relationships)

### Vague modifiers

- very, really, quite, rather, pretty, fairly (cut these)
- seamless, effortless, frictionless (describe the actual mechanism)
- simply, just, easily (implies the reader should find it easy; they might
  not)
- obviously, clearly (if it's obvious, don't say it)

### Outdated or exclusionary

- blacklist, whitelist (use "blocklist" and "allowlist")
- master/slave (use "primary/secondary" or "leader/follower")
- grandfathered (use "legacy status" or "exempted")

## Phrases to Rewrite

| Instead of | Write |
|---|---|
| "The AI decided..." | "The agent executed the configured logic..." |
| "The agent learned from..." | "The model was trained on..." |
| "The bot is smart enough to..." | "The agent identifies patterns in..." |
| "Simply deploy the agent..." | "Deploy the agent by..." |
| "Magic happens when..." | "The system coordinates agents by..." |
| "Our AI understands..." | "The agent processes..." |
| "Trust the agent to..." | "Configure the agent to..." |

## Special Cases

**x402** — Always lowercase. Never "X402" or "X-402."

**Neoteams vs. neoteam** — Capitalize when referring to the category we're
building: "We're creating the category of Neoteams." Use lowercase for
generic use: "A neoteam includes humans and agents."

**Agent vs. AI** — Use "agent" as the default term. Only use "AI agent" for
initial context-setting or when speaking to audiences unfamiliar with the
concept. Never "bot," "robot," or "automaton."

**Provenance** — This is our key differentiator word. Use it precisely:
"Provenance is cryptographic proof of what an agent did." Not "logs," "audit
trails," or "records" (too generic). Not "blockchain" (too technical).

**Federation** — Use when discussing agents working across organizational
boundaries. Not "integration" (implies connecting systems) or
"collaboration" (implies human-like teamwork).
