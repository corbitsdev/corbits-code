# Ink freeze policy (superseded)

**Status:** historical — Ink has been deleted from the repo; the OpenTUI cutover is complete.

This document described the freeze rules that governed changes to the Ink-based TUI during the OpenTUI migration. The Ink/React tree no longer exists in this repo (no `.tsx` files remain), so the policy no longer applies. See `docs/tui-cutover-readiness.md` for the current state of the OpenTUI shell.
