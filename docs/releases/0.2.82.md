# Corbits 0.2.82

Patch release after the Corbits rename: safety hardening, subagent performance, TUI polish, persistence correctness, and first-class multi-platform packaging.

## Highlights

- **`corbits exec`** and a local capability eval harness for non-interactive runs and regression gates
- **FIFO approval queue** so plan / permission / operator gates no longer race
- **Release packaging** via `scripts/release.sh` (macOS + Linux binaries, debs, Homebrew tap)
- **Safer shell & tools**: fail-closed multi-segment grants, workspace path checks, MCP scrub, secret denylist, tool-output URI rejection, edit_file verification
- **Faster subagent strip**: snapshot caching by revision, tool-name dedup, skip unused turn-history retention
- **TUI polish**: theme-routed chat chrome, error caps + pass/fail glyph, diff washes and collapsed-row stats
